#  Signal Processing Learning Game (MATLAB)

An interactive MATLAB App Designer project to visualize and understand key concepts of Analog & Digital Communication.

##  Features
- Noise reduction (SNR improvement)
- AM Modulation & Demodulation
- Bit Detection using Thresholding
- BER (Bit Error Rate) analysis
- Final system performance evaluation

##  Levels
1. Noise Reduction
2. Modulation
3. Demodulation
4. Bit Detection
5. System Performance Analysis

##  Metrics Used
- SNR (Signal-to-Noise Ratio)
- BER (Bit Error Rate)
- Error Count
